# Logos de EL MUNDO DEL PERNO

Para cambiar la marca visual, reemplaza los archivos conservando sus nombres:

- `logo.png`: logo usado principalmente sobre fondos oscuros.
- `logo-dark.png`: logo usado principalmente sobre fondos claros.

Estos dos archivos aparecen en las cabeceras de tienda, administración y checkout,
además de autenticación y páginas legales. Vite los incluye al compilar el frontend.

Hay otros dos recursos en la carpeta `public`:

- `public/logo-dark.png`: logo público que recibe el formulario de pago Niubiz.
- `public/favicon.ico`: icono pequeño mostrado en la pestaña del navegador.
